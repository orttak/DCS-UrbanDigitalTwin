### 4
cityjson i 3ddbye gonder, sonra export et, json ve gml olarak, 3ddb uretecek.

**Cevap / Yontem:**
- Amaç: 3DCityDB (citydb-tool) import/export cikisinda CityJSON ve CityGML tarafinda ne kayboluyor?
- Aynı dataset icin iki fark raporu uret:
  - CityJSON -> DB -> CityJSON (json-json)
  - CityJSON -> DB -> CityGML (gml validate + gml stats)

**CityDB komutlari (ornek, Docker Compose DB varsayimi):**
- Import CityJSON:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest import cityjson -H citydb -d citydb -u postgres -p postgres /input/Ingolstadt.city.json`
- Export CityJSON:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export cityjson -H citydb -d citydb -u postgres -p postgres --cityjson-version 1.1 --no-json-lines -o /input/export/q4_from_db.city.json`
- Export CityGML:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export citygml -H citydb -d citydb -u postgres -p postgres -o /input/export/q4_from_db.gml`

**Karsilastirma:**
- JSON diff:
  - `python3 scripts/compare_cityjson.py data/Ingolstadt.city.json data/export/q4_from_db.city.json --out dev/test/reports/q4_cityjson_db_roundtrip.json`
- GML stats/diff (GML-GML yapacaksan):
  - `python3 scripts/compare_citygml.py data/export/q4_from_db.gml data/export/q4_from_db.gml`  *(ornek; gercek diff icin iki farkli GML ver)*
- GML validate (opsiyonel ama iyi):
  - `python3 scripts/export_validate_gml.py --output data/export/q4_from_db.gml`

### 5

blenderda geometrik degisiklikler, ornegin lod3 detayi ve farkini test et

**Cevap / Yontem (3 asamali karsilastirma):**
1) CityGML (orijinal) -> DB -> CityGML (export1) karsilastir (GML-GML)
2) Export1 -> (DB->CityJSON) -> Blender import/export (hic degisiklik yok) -> DB -> CityGML (export2) karsilastir (export1 vs export2)
3) Blender'da geometri degisiklikleri (LOD3 detayi) -> DB -> CityGML (export3) karsilastir (export2 vs export3)

**Komut iskeleti:**
- Import CityGML:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest import citygml -H citydb -d citydb -u postgres -p postgres /input/<dataset>.gml`
- Export CityGML (export1):
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export citygml -H citydb -d citydb -u postgres -p postgres -o /input/export/q5_export1.gml`
- Export CityJSON (Blender icin):
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export cityjson -H citydb -d citydb -u postgres -p postgres --cityjson-version 1.1 --no-json-lines -o /input/export/q5_from_db.city.json`
- Blender roundtrip (degisiklik yok):
  - `blender -b --python scripts/blender_test_cycle.py -- --input data/export/q5_from_db.city.json --output data/export/q5_blender_roundtrip.city.json`
- Re-import CityJSON (Blender cikisi) ve tekrar export (export2):
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest import cityjson -H citydb -d citydb -u postgres -p postgres /input/export/q5_blender_roundtrip.city.json`
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export citygml -H citydb -d citydb -u postgres -p postgres -o /input/export/q5_export2.gml`

**Karsilastirma:**
- `python3 scripts/compare_citygml.py data/export/q5_export1.gml data/export/q5_export2.gml --out dev/test/reports/q5_gml_export1_vs_export2.json`
- Blender cikisi CityJSON'u kontrol:
  - `python3 scripts/compare_cityjson.py data/export/q5_from_db.city.json data/export/q5_blender_roundtrip.city.json --out dev/test/reports/q5_cityjson_db_vs_blender.json`
