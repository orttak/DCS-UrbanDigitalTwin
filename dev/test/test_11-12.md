### 4
cityjson i 3ddbye gonder, sonra export et, json ve gml olarak, 3ddb uretecek.

**Cevap / Yontem:**
- Amaç: 3DCityDB (citydb-tool) import/export cikisinda CityJSON ve CityGML tarafinda ne kayboluyor?
- Aynı dataset icin iki fark raporu uret:
  - CityJSON -> DB -> CityJSON (json-json)
  - CityJSON -> DB -> CityGML (gml validate + gml stats)

**CityDB komutlari (ornek, Docker Compose DB varsayimi):**
- Import CityJSON:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest import cityjson -H citydb -d citydb -u postgres -p postgres /input/Ingolstadt.city.json`
- Export CityJSON:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export cityjson -H citydb -d citydb -u postgres -p postgres --cityjson-version 2.0 --no-json-lines -o /input/export/q4_from_db.city.json`
- Export CityGML:
  - `docker run --rm -v ${PWD}/data:/input --network docker_default 3dcitydb/citydb-tool:latest export citygml -H citydb -d citydb -u postgres -p postgres -o /input/export/q4_from_db.gml`

**Karsilastirma:**
- JSON diff:
  - `python3 scripts/compare_cityjson.py data/Ingolstadt.city.json data/export/q4_from_db.city.json --out dev/test/reports/q4_cityjson_db_roundtrip.json`
- GML stats/diff (GML-GML yapacaksan):
  - `python3 scripts/compare_citygml.py data/export/q4_from_db.gml data/export/q4_from_db.gml`  *(ornek; gercek diff icin iki farkli GML ver)*
- GML validate (opsiyonel ama iyi):
  - `python3 scripts/export_validate_gml.py --output data/export/q4_from_db.gml`
- CityDoctor validate (CityGML kalite raporu):
  - `python3 scripts/validate_matrix.py data/export/q4_from_db.gml --reports-dir dev/test/reports --out dev/test/reports/q4_from_db_gml_validation_matrix.md`
